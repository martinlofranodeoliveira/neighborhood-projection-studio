# Design boundaries

Maintained sklearn owns full PCA/SVD and block pairwise distances. Original
behavior is bounded admission/ownership, deterministic rank receipts, integer
fraction accounting and complete report serialization. The four accepted core
files stay byte-identical while CLI/files/package/stdio adapters are integrated.

The independent literal rank kernel has deliberately tied integer coordinates;
it tests ordering/counts independently of PCA. Native integration uses real fits,
full spectra, weighted reconstruction and a tie-free scalar reference115/128.
Observed sample reports are separate from handliteral serializer DTOs. A maximum
native distance run alone does not prove a maximum report fits: the actual full
report exceeds16 MiB and the correct terminal state is budget rejection.

Seven runtime packages are separate from the twelve build and sixteen build/test
wheels. Source, sdist, original/rebuilt wheels and installed code/notices are
compared. A fresh clean runtime has no source checkout/compiler/build/test setup.
Python helper tests are not a browser or hosted-CI result. Original MIT is
separate from actual retained legal files, including conservative base/prior
materials that are not asserted to be an exact binary link graph.
