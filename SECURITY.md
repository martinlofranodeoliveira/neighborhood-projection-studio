# Local input and evidence boundaries

Use the explicit bounded numeric JSON protocol. No executable expression,
model/pickle input, plugin, remote URL acquisition or telemetry is accepted by
analysis. Paths/values/SDK exception text are omitted from error envelopes.
Reports contain the admitted original numeric table; treat exported files as
data intentionally disclosed to their readers.

A regular no-follow leaf read checks observed metadata and owned bytes. It is
not a directory sandbox or an adversarial concurrency guarantee. Byte limits
are not recursion/RSS isolation. Native OOM/kill/timeouts are incomplete outer
execution; stdout success requires complete framing and exit0. Imported report
hashes/producer metadata do not authenticate execution. Keep last valid state
on import rejection and render labels as text.

Report reproducible issues through the repository's issue channel with synthetic
inputs, source SHA and actual observed status; omit private data/credentials.
Do not interpret a new package or its diagnostics as production, safety,
security, statistical-quality or certification evidence.
