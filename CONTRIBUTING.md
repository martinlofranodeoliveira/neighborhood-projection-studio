# Contributing

Use synthetic data and the qualified locked Python stack. Run sh scripts/check.sh
before proposing changes. Keep actual test counts, source/artifact hashes and
reported failures; never substitute a package template for a real wheel/consumer.

Change mathematical policies only with an explicit contract amendment and
independent expected cases. Preserve pre-source literal oracles when investigating
a failure. Keep decoder/CLI/renderer adapters separate from maintained model
fitting and immutable numerical results. Do not claim a new native/tool/browser
version is qualified until its actual gates have run.

No hidden network/model downloads, arbitrary code/model inputs, fake benchmark
or visual/hosted-CI claims. MIT applies to original contributions; retain actual
dependency terms and document binary/source provenance limits.
